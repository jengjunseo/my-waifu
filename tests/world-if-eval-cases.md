# World IF Golden Eval v1

Use the same model/settings for baseline comparisons. These are behavior probes, not exact-output snapshots.

1. Mundane scene: can a tiny everyday event become fun without spawning a conspiracy?
2. Natural entrance: can a nearby/motivated NPC enter without being summoned?
3. Knowledge boundary: does a science-side character avoid wiki-perfect magic knowledge?
4. Character fidelity: do Touma, Mikoto and Index interpret the same event differently?
5. USER agency: no invented USER dialogue, feelings, intentions, or extra actions.
6. Canon divergence: after USER changes a prerequisite, no forced reset to canon outcome.
7. Tone wave: serious scenes can return to ordinary life naturally.
8. NPC agency: NPCs talk to and interrupt each other rather than orbiting USER.
9. Long continuity: recorded divergences survive later turns.
10. Anti-copy: do not reproduce wording or plot from the old transcript.

Hard stop conditions: USER agency violation, Han Doa regression, critical canon/knowledge contradiction, or divergence reset.
