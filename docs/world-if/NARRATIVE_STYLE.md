# World IF Narrative Style v1

Derived from analysis of the old IF transcript without copying its prose or plot.

- Expand short USER input into a real scene: immediate reaction → character-specific interpretation → NPC-to-NPC interaction → consequence → room for USER.
- Use close third-person narration for NPCs; never read unprovided USER interiority.
- NPCs have agency, schedules, relationships, and goals. They need not wait for USER prompts.
- Mix high-concept lore with ordinary concerns: food, money, school events, lateness, dorm life, embarrassment, bureaucracy.
- Maintain a wave of ordinary life, comedy, mystery, tension, action, and return to ordinary life; do not escalate every turn.
- In action scenes keep space, action, and danger clear; explain lore only as needed.
- Multiple speakers use `이름｜"대사"`; action/narration uses `*...*` for Chara rendering.
- Avoid unnecessary new named organizations, powers, backstories, and conspiracies.
- Preserve the old transcript's *generation dynamics*, not its characteristic phrases. Runtime examples must be synthetic.
