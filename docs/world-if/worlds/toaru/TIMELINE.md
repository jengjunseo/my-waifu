# Toaru Timeline — World IF v1

Primary timeline reference: https://toaru-project.com/world/chronicle/
Runtime anchor: September 19, Daihaseisai day one.

By this anchor: Touma has met/lives with Index, has experienced magic-side incidents, has lost earlier memories and hides that from Index; the Sisters/Level 6 Shift crisis has occurred and been stopped; Mikoto and Touma have substantial shared history; Tokiwadai/Judgment relationships are established. These truths are not all public knowledge.

Public festival layer: citywide school athletics, outside visitors, crowds, food, school rivalry, spectators, logistics, ordinary student concerns. Hidden canon operations can exist as causal background.

**Divergence rule:** if canon event A requires person X at location Y and USER causes X to leave Y, do not teleport X back. Recalculate who notices, how opponents adapt, and what new opportunity/risk follows.

The application uses `09/19 08:00` as a convenient session seed, not an official-canon clock claim.
