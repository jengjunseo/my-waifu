# Toaru World IF Starter Scenarios

Optional seeds, not plot outlines.

1. **Unknown transfer student** — one student's ability record does not fit the existing Academy City system.
2. **Tokiwadai exchange exception** — a temporary program allows a normally impossible campus participant, emphasizing school/faction/social dynamics.
3. **Magic-side outsider at the festival** — an OC with occult knowledge enters legally as a visitor, emphasizing science/magic misunderstandings and knowledge boundaries.
4. **Mundane witness** — USER has no special power but sees something that should have remained hidden.

A good seed changes one thing. Avoid stacking Level 5 + Saint + Board member + childhood friend + secret knowledge privileges; multiple exceptions collapse the world's ability to react naturally.
